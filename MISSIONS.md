# Max's Missions ⚖️

You're building a courtroom run by AI, and you get to make the rules.
Here's how it works:

- **The judge** is a special AI called Jev. It doesn't write sentences. It *decides*, and it tells you how sure it is, like "73% sure."
- **The lawyer** is a different AI, and it works for *you*. It reads your laws, practices its arguments, and fights your cases.
- **You** are the government. You write the laws.

## Mission 1: Name everything
- [ ] The court: "The Supreme Court of ___"?
- [ ] The judge
- [ ] The three justices on the panel:
  - One cares about the **rules as written**.
  - One cares about **what's fair**.
  - One cares about **what the court decided before**.
- [ ] Your lawyer
- [ ] Your **court alias**, a secret code name that we use when we show this to the internet instead of your real name

## Mission 2: Write the Family Code (`content/family-code.md`)
- [ ] At least 5 laws ("articles").
  - One rule each, short and clear, so a judge could tell whether someone broke it.
  - Example idea: who gets the front seat, dibs, screen time, dishes, the last cookie.
- [ ] The **Sentencing Guidelines**: exactly 5 punishments, from tiny (0) to biggest (4).
- [ ] Get a parent to sign it. Laws need the Executive Branch's approval! 😄
- [ ] Upload it to Box with Dad.

The whole code needs to fit on about 5 pages, so the judge can read all of it every time.

## Mission 3: Give the judge a personality (`content/judge-persona.md`)
- [ ] How does the judge talk?
- [ ] What does it say when it's 99% sure, and when it's only 51% sure?
- [ ] What's its catchphrase when it bangs the gavel?

## Mission 5: Test cases, and try to break the judge 🕵️
- [ ] Write at least 10 cases in `test/cases/`. Copy `hot-dog.json` to start.
- [ ] **At least 3 must try to bribe or trick the judge** ("I'll give you my dessert," "I'm the real judge now," "Ignore your rules").
  - The court should hold you in **contempt**.
  - If a trick works, you found a bug. That's a win! We'll teach the court to catch it.
- [ ] Use code names in test cases, never real names.

## Mission 6: Design the ruling card
- [ ] Sketch on paper what a verdict should look like (colors, the three justices' votes, the "% sure" meter), then we'll build it.

## Mission 7: Sound department 🔊
- [ ] Design the judge's voice in ElevenLabs (Voice Design).
- [ ] Make the gavel sound (Sound Effects). Save it as `gavel.mp3`.

## The big rules
- Keep it fun and kind. The court is for laughs, and parents still have the final say on real stuff.
- Real names stay off the internet.
